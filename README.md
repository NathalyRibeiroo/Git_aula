## Git e GitHub

* Git: é um sistema de controle de versão distribuído e gratuito que registra todas as alterações feitas em arquivos e códigos de um projeto ao longo do tempo

* GitHub: é uma plataforma de hospedagem de código-fonte e arquivos na nuvem que usa o sistema de controle de versão Git

* Push: é um comando do Git usado para enviar as alterações salvas no seu computador (repositório local) para um servidor online (repositório remoto, como o GitHub ou GitLab)

* Pull:baixa as atualizações de um repositório remoto (como o GitHub) e as junta imediatamente com o seu código local
